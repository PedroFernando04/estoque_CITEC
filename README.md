# 📦 estoque_CITEC

Sistema de controle de estoque desenvolvido em Java, com interface web para gerenciamento de produtos.

---

## 📌 Descrição

Aplicação voltada para controle de estoque, permitindo gerenciar produtos, entradas e saídas, com suporte a interface web.

---

## 🚀 Funcionalidades

* 📦 Cadastro de produtos
* ➕ Registro de entrada de itens
* ➖ Registro de saída de itens
* 📊 Visualização do estoque
* 📁 Upload de arquivos (pasta `uploads`)

---

## 🛠️ Tecnologias

* Java
* Spring Boot
* Thymeleaf
* HTML
* CSS

---

## 📁 Estrutura

```bash
estoque_CITEC/
│-- estoque/      # Código principal
│-- uploads/      # Arquivos enviados
│-- .idea/        # Configuração da IDE
```

---

## ⚙️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/PedroFernando04/estoque_CITEC.git
```

2. Abra o projeto em uma IDE (IntelliJ recomendado)

3. Execute o projeto Java

---

Fornecer uma solução simples para controle de estoque, aplicando conceitos de desenvolvimento web com Java.
